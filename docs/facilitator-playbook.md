# Facilitator reference

Present from [DEMO-GUIDE.md](../DEMO-GUIDE.md), not from a coverage matrix.
The local story is a synthetic research review request and one name rule.
Use one primary Copilot interface; explain other interfaces only when relevant.

## Purpose checks

| Element | Why it belongs | What it must not become |
|---|---|---|
| Synthetic study snapshot | Gives the request a concrete HLS context | A patient browser or clinical conclusion |
| JuliaHealth library calls | Demonstrate discovery and reuse of scientific tools | A homegrown cohort engine or reimplementation of the tutorial package |
| Required name | A business rule people can observe in seconds | Authentication or proof of requester identity |
| Accessible correction | Connects acceptance criteria to a usable result | A claim of full accessibility certification |
| Julia/API/browser tests | Deterministic evidence independent of the agent | A green check manufactured by weakened assertions |
| Business handoff | Connects code to BA/research-team understanding | Automatically approved requirements |
| GitHub continuation | Shows delegation, review and CI on the same task | A tour of unrelated products or automatic publication |

## Preflight

- Root setup, verified synthetic data, reference tests, and a fresh local run.
- Start's intentional gap observed; unrelated setup failures resolved.
- Actual Julia/Node/VS Code versions and available Copilot harness recorded.
- Real permission controls checked; no claim that instructions enforce access.
- Package compilation/data download finished before presenting.
- One browser tab and one editor; no private context attached or copied.
- Remote actions excluded unless separately approved for named resources.

## Three business acceptance criteria

1. An invalid name creates nothing and produces the exact accessible error.
2. A valid name is trimmed, accepted and listed only after server success.
3. Correcting the input clears the stale error and allows keyboard submission.

The existing synthetic study must remain unchanged: 2,694 distinct people,
1,677 in tutorial concept 28060. Duplicate condition rows must not inflate it.

## Fallbacks

| Failure | Honest response |
|---|---|
| Package/data setup fails | Stop and repair setup; no fake counts or substitute patient data |
| Copilot unavailable | Show the labeled reference/fixture rehearsal; do not call it live agent output |
| Agent expands scope | Reject unrelated changes and return to the agreed rule |
| Test fails | Show the failure; investigate without deleting assertions |
| Review finds nothing | Record that result; use the deterministic regression test |
| Hosted access missing | Explain the local workflow definition; do not claim a GitHub run |
| Screen reader not tested | State that automated accessibility assertions are not a manual audit |
