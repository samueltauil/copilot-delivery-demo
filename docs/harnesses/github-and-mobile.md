# GitHub.com, cloud agent, mobile, and other IDEs

Use docs/web-scenarios.md for the distinct issue assignment, manual PR review,
and optional automatic-review triggers. Publication and all remote actions are
separately approved. Cloud environments see approved hosted refs, not arbitrary
uncommitted local files or the presenter's local browser/server.

Mobile can support available repository discussion/review/follow-up paths;
verify current feature/account support. It is not a replacement for this local
application or automated browser-test environment. Remote session control, if
available and approved, is optional and not a workshop prerequisite.

Other Copilot IDEs can reuse ordinary prompts, requirements and handoff files.
Native prompt-file/customization support varies; do not claim tested compatibility
without running the same evidence gates. No app/harness abstraction layer is
required. Each destination must recheck context, approvals and permissions.
Status: documented, not hosted/mobile exercised.
