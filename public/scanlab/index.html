What is computed, and what is proved?

The fixed 96 × 96 acquisition uses KomaMRI's bundled BrainWeb-derived digital brain phantom: published synthetic anatomy, not a patient record. KomaMRI computes the CPU acquisition; MRIReco reconstructs it. DICOM.jl writes a derived 16-bit Secondary Capture file and reopens it. The displayed image comes from those decoded pixels, rescaled to arbitrary units.

Stored integer pixels must survive exactly. Quantization error against the floating-point reconstruction must stay within half a stored intensity step. This is image-integrity evidence, not diagnostic validation. A pinned baseline retains its image, run ID, DICOM bytes, and parameters through subsequent runs.
