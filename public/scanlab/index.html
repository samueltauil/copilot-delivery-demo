          Technical details Fingerprints, DICOM tags and how the scan was made

          Showing the details of this scan.

          A fingerprint (SHA-256) is a short code computed from a file’s contents. If a single pixel changed, the code would change.

          Labels stored inside the saved file. This is a practice image saved as a Secondary Capture, not a real MRI study. It is not a conformance certificate.

          DICOM tags in the selected scan
          TagNameValue

          The practice brain is one slice of a public digital brain model (BrainWeb) that ships with KomaMRI. KomaMRI simulates the scan on this computer’s CPU, MRIReco turns the signal into a picture, and DICOM.jl saves the picture as a DICOM file and opens it again. The image on screen is read back from that file.

          The file check compares every pixel read back with what was saved. Stored pixels must match exactly, and rounding to 16-bit brightness levels must stay within half a step. This is evidence about image files, not a medical test. A reference you keep is stored whole, so later scans cannot change it.
